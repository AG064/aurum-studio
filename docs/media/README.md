# Documentation visuals

These images accompany the Aurum Studio 0.2 documentation:

- `aurum-banner.svg`: original, editable vector graphic. It describes the product and is not an application screenshot.
- `studio.png`: the running Windows Studio interface managing Orbit Break, including packaging and platform-export controls.
- `orbit-break-menu.png`: the example's actual title screen.
- `orbit-break-gameplay.png`: the example running its second wave, with health, score, dash and auto-fire visible.

The screenshots were captured from the working local application and Windows game package on 29 September 2026. They are not generated mockups. Paths visible in Studio identify the demonstration checkout; they are not installation requirements. The game title includes DEBUG because the portable package uses the full runtime executable rather than a stripped export template.

The artwork and screenshots are provided with the repository under its MIT license. The game uses original procedural geometry, generated audio and an SVG icon; underlying runtime notices are included by the packaging operation.
