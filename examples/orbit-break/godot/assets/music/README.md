# Orbit Break score

The three original instrumental loops share a four-bar motif and D minor
harmonic material. Breakwater uses a restrained pulse, Aperture lifts the pluck
part and removes the drum layer, and Ash Foundry adds a heavier low rhythm.
The game changes arrangement with the station and lowers it under menus.

These are locally synthesized assets, with no third-party recordings or network
audio requests. Their arrangement is defined in `tools/generate_score.gd` and
can be reproduced with the bundled engine and `ORBIT_SCORE_OUTPUT` set to a
disposable output directory. The generated wave files are covered by the
repository's MIT license.
