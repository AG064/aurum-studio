# Display type

`BarlowCondensed-SemiBold.ttf` is the unmodified Barlow Condensed SemiBold font
by the Barlow Project Authors. It is used for large instrument values, titles
and module names. Body text uses Godot's bundled fallback font.

The font is bundled locally, with no runtime font requests.

Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed
Author project: https://github.com/jpt/barlow
