# Documentation visuals

These images accompany the Aurum Studio 0.2 documentation:

- `aurum-banner.svg`: an earlier decorative vector banner, retained for history and no longer used in the README.
- `studio.png`: the actual browser workbench, with Orbit Break in its second wave and the live inspector open.
- `orbit-break-menu.png`: the example's actual browser-rendered title screen.
- `orbit-break-gameplay.png`: the browser game running its second wave.
- `orbit-break-workshop.png`: the untimed workshop inside the working Studio interface.
- `design-reference.png`: the selected first visual concept. This is a design reference, not a running-app screenshot.

The screenshots were captured from a disposable project in the working local application on 29 September 2026, at a 1488 by 1056 browser viewport. They are not generated mockups. Paths visible in Studio identify the demonstration checkout; they are not installation requirements. Browser-test screenshots and traces are also retained by GitHub CI.

The artwork and screenshots are provided with the repository under its MIT license. The game uses original procedural geometry, generated audio and an SVG icon; underlying runtime notices are included by the packaging operation.
